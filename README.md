Hulhumalé Hospital Website by Yanis Saeed

=========================================

A responsive and informative hospital website developed for Hulhumalé Hospital (HMH) as part of a Web Development class project. This website provides comprehensive information about the hospital's services, vision, mission, and contact details to serve the community of Hulhumalé, Maldives.



Project Timeline: December 21, 2025 - January 27 2026.

Development started: December 21, 2025

All HTML CSS completed: January 19, 2026 

Final review completed: January 27, 2026

Total development time: 5 weeks

============================================

Features Implemented

1.Horizontal Navigation Bar

Located in the <header> section of all pages (index.html, about.html, vision.html, contact.html). Includes hospital logo and navigation links to all four pages.


2.Images and Visual Content

Header Logo: Assets/Logo/logo.png - appears on all pages

Footer Logo: Assets/Logo/logo_footer.png - appears on all pages

Banner Images: Custom banner sections (.banner, .banner-2, .banner-3, .banner-4) on each page

Image for appointment: Assets/Banner/banner_bottom.jpg - appears on index.html bottom below hospital information

Insurance Logos: Found in index.html within .insurance-container section

Service card Images: Assets/Images Categories - appears on service cards on home page


3.Contact/Feedback Form

Located in contact.html - includes Name, Email, Phone, Subject, and Message fields with required field validation.


4.Table for Hospital Information

Found in index.html under the "Hospital Information" section. Table class: .HMH-info-table displays 8 departments with their visiting hours and service categories.


5.Home Page (index.html)

Features a welcome banner, 12 service cards in a grid layout, hospital information table, Image showing how to get appointment in Dhivehi, and insurance coverage section.


6. About Us Page (about.html)

Contains hospital history and overview in .page-content section, covering establishment (2004) to present day operations.


7. Vision & Mission Page (vision.html)

Displays the hospital's Vision, Mission, and five core Values (Innovation, Unity, Learning \& Development, Sustainability, Excellence) within .page-content section.


8. Contact Us Page (contact.html)

Features three contact information cards in .contact-grid layout, contact form, and multiple location listings.


9.Responsive Design

The website is designed with responsive principles to ensure optimal viewing across:

-Desktop computers (1024px and above)

-Tablets (768px - 1023px)

-Mobile devices (320px - 767px)

Getting Started

- A modern web browser (Chrome, Firefox, Safari, Edge)

- Text editor (Notepad++, VS Code, Sublime Text, Atom, or similar)


A. Open the website:

- Simply open `index.html` in your preferred web browser

- Or use a local development server (like Live Server in VS Code using Extension)


B. Usage:

1. Open `index.html` in any modern web browser to view the home page

2. Use the navigation bar to explore different sections:

- Home: View services, hospital information table, and insurance coverage

- About Us: Learn about the hospital's history and development

- Vision & Mission: Understand the hospital's core values and commitment

- Contact: Access contact information and submit inquiries via the form
